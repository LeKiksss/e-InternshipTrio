# e-InternshipTrio
This repo represents the work of 3 interns working on developing 3 use cases for the mobile app of e& in the UAE. 

**Network and Bill Intelligence:** Helps users understand network performance, bill breakdowns, anomalies, and plan suitability.
- **Complaint Intelligence and Registration:** Guides users through submitting, summarizing, and tracking customer complaints.
- **Roaming Package Advisor:** Recommends a suitable roaming package based on destination, travel dates, and expected usage.
